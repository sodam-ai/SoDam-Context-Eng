SoDamContext — 왕초보 단계별 가이드 👶

컴퓨터·AI·메신저·스마트폰이 처음인 분도 그대로 따라 할 수 있게, "지금 이걸 누르세요" 식으로 설명합니다. (간단 요약·명령어·아키텍처·라이선스 전체는 같은 폴더의 README.md 에 있어요.)

⚠️ 정직한 안내(2026-07-18 기준): 지금 작동까지 확인된 기능은 검진(점검)·문진(만들기)·처방(다듬기)·동기화(두 설명서 비교)·예방(저장 전 자동 차단) 다섯 가지예요 — 클로드코드·코덱스 둘 다 실제로 써서 확인 완료했어요. **정기 점검 알림·참고 점수(건강점수)**는 코드를 다 만들고 자동 시험·명령줄 직접 실행으로 확인했지만, 실제 대화 화면에서 자연스럽게 나오는지는 아직 추가 확인 전이에요. ⚠️ 클로드코드 호출 방식이 바뀌었어요(2026-07-18): 예전엔 말로("설명서 점검해줘") 해도 가끔 됐지만, 지금은 /sodam-context:checkup처럼 슬래시 명령을 정확히 입력해야만 작동해요. 코덱스는 영향 없어요 — 말로 부르는 방식 그대로예요. 이 도구는 컴퓨터(Windows·macOS) 에서 돌아가요 — 휴대폰 앱이 아니에요.

먼저 알아둘 것

  1. 이 도구는 클로드코드 안에서 작동해요. (클로드코드 = AI랑 글로 대화하며 코딩하는 컴퓨터 프로그램)
  2. 한 번만 설치하면 됩니다. 그다음부턴 명령어만 치면 돼요.
  3. "입력창" = 클로드코드에서 글을 치는 칸. 이 가이드에서 "입력창에 ~치세요"는 거기에 친다는 뜻이에요.

💡 "AI 설명서"란? AI가 일 시작 전에 읽는 CLAUDE.md·AGENTS.md 파일이에요. "이 프로젝트는 이렇게 다뤄줘"라고 적어 두는 쪽지랍니다.

1단계 준비물 확인

입력창에 아래를 치고 Enter:

!node --version
  • v18 이상(예: v20, v22) 숫자가 나오면 → 준비 끝 ✅
  • 빨간 글씨/없음이 나오면 → 인터넷 브라우저로 nodejs.org 접속 → 초록색 LTS 버튼 눌러 설치 → 컴퓨터 다시 시작.

(코덱스도 쓰려면 !git --version 도 쳐서 숫자가 나오는지 확인하세요. 없으면 git-scm.com 에서 설치.)

2단계 설치하기

입력창에 아래 두 줄을 한 줄씩 붙여넣고 각각 Enter:

/plugin marketplace add sodam-ai/SoDam-Context-Eng
/plugin install sodam-context
  • "설치됐어요" 비슷한 메시지가 나오면 성공이에요.
  • (내 컴퓨터 폴더로 직접 설치하는 경우엔, 첫 줄의 sodam-ai/SoDam-Context-Eng 자리에 그 폴더 경로를 넣으세요.)

2-B단계 코덱스 수동 설치

코덱스(OpenAI Codex)는 플러그인 마켓이 없어서 저장소를 통째로 받아 그 안에서 씁니다. (스킬 폴더만 복사하면 검진 도구가 쓰는 lib·rules 폴더가 빠져서 "파일을 찾을 수 없어요" 오류가 나요.)

  1. 저장소 받기 — 터미널(명령 프롬프트)에 한 줄씩:

    git clone https://github.com/sodam-ai/SoDam-Context-Eng.git
cd SoDam-Context-Eng

    (이미 받아둔 폴더가 있으면 그 폴더로 이동하면 돼요.)

  2. 코덱스를 이 저장소 루트 폴더에서 시작하세요. (루트에 AGENTS.md·skills·lib·rules가 다 있어요.) ⚠️ 루트가 아닌 다른 폴더에서 실행하면 "파일을 찾을 수 없어요" 오류가 나요.

  3. 코덱스에서 자연어로 시험:

    내 AGENTS.md 건강검진 해줘
    • 검사할 파일은 절대경로로 알려주세요 (예: C:\내프로젝트\AGENTS.md).
    • (코덱스는 /명령어 방식이 아니라 자연어로 스킬이 동작해요.)
    • 더 자세한 설치·FAQ는 저장소의 codex/README.ko.md 를 참고하세요.

💡 원클릭 설치(선택, Windows): 저장소의 codex/install.ps1을 실행하면 위 1번(준비물 확인·저장소 받기·AGENTS.md 만들기)을 대신 해줘요. 이 저장소는 비공개라 스크립트를 처음 받으려면 1번의 git clone은 딱 한 번 직접 해야 해요.

한글 용량 주의: 한글 1글자 = 3바이트예요. 짧아 보여도 실제 용량이 커서 코덱스 32 KiB 한도에 걸릴 수 있어요. 검진 시 자동으로 알려드려요.

3단계 껐다 켜기

방금 설치한 건 다시 켜야 나타나요.

  • 입력창에 exit 치고 Enter → 창을 X로 완전히 닫기
  • 다시 클로드코드를 켜기 (터미널이면 claude 입력)

확인: 입력창에 / 만 쳐보세요. 목록에 sodam-context:checkup·sodam-context:intake·sodam-context:treat·sodam-context:sync 가 보이면 준비 완료! 🎉

4단계 설명서 만들기

아직 AI 설명서(CLAUDE.md)가 없다면 만들어 봅시다. (이 기능 이름 = 문진)

  1. 입력창에 치기:

    /sodam-context:intake

  2. "어느 폴더에 만들까요?"라고 물으면 → 만들 폴더 경로를 알려주거나 "지금 이 폴더" 라고 답하기.

  3. AI가 쉬운 질문을 하나씩 해요. 막히면 이렇게 답해도 돼요:

    질문 이렇게 답하면 돼요
    무슨 프로젝트예요? 그냥 연습용
    무슨 언어·도구로? 모름
    꼭 지킬 규칙은? 한국어로 답해줘
    하면 안 되는 건? 비밀번호를 코드에 적지 마
    말투는? 쉽게, 짧게

  4. AI가 만들 내용을 먼저 보여주고 "이대로 만들까요?"라고 물어요. → 마음에 들면 네 라고 답하면 그때 파일이 생겨요. (묻기 전엔 절대 안 만들어요)

  5. "잘 만들었어요!" 가 나오면 끝. 이어서 "검진도 해볼까요?"라고 물으면 네 하면 점검까지 해줘요.

5단계 점검하기

이미 CLAUDE.md가 있는 폴더라면: (이 기능 이름 = 검진)

  1. 입력창에 치기: 
    /sodam-context:checkup
  2. "어느 파일을 볼까요?"라고 물으면 → 그 파일 경로를 알려주기 (예: C:\내폴더\CLAUDE.md).
  3. 잠시 후 쉬운 리포트가 나와요:
    • "문제 ○건" 처럼 개수가 가장 먼저 나와요
    • 비밀번호/키가 있으면 가린 채(sk-ant-…REDACTED)로만
    • 낡음·미정제 같은 항목은 "의심" 으로(확정 아니라 참고용)
    • 통째 붙여넣기(코드블록이 너무 길게 그대로 있는 경우)는 "확정" 문제로 잡아요(길이만 보고 판단, 내용은 안 읽어요)
    • 참고 점수(예: "85점")가 개수 뒤에 보조로 붙어요 — 항상 "참고용(검증 전)" 이라는 말이 같이 나와요(아직 여러 사람 데이터로 다듬은 공식 점수가 아니라는 뜻)
    • 마지막으로 점검한 지 30일이 넘었으면 "다시 점검해볼까요?" 정도로 짧게 안내해요(자동 알림이 아니라, 점검을 실행하는 그 순간에만 비교해요. 30일이 안 지났으면 이 말 자체가 안 나와요)
    • 더 궁금하면 왜요? 라고 답하면 이유를 설명해줘요.

6단계 다듬기

검진에서 문제를 찾았다면 안전하게 다듬을 수 있어요. (이 기능 이름 = 처방, 실사용 확인 완료)

  1. 입력창에 치기: 
    /sodam-context:treat
  2. 백업을 먼저 뜨고, 무엇을 바꿀지 먼저 보여줘요.
  3. 네 라고 해야만 실제로 고쳐요(중복 줄·불필요한 빈 줄 정리).
  4. 마음에 안 들면 되돌리기로 백업에서 원래대로 복구할 수 있어요.
  5. 안전·금지 규칙 줄(예: "절대", "never", "비밀번호 금지")은 자동으로 보존돼요(안 지워요).
  6. 엉뚱한 위치는 아예 못 건드려요: 컴퓨터의 중요한 폴더(예: 로그인 정보가 든 폴더, 시스템 폴더)를 실수로 지정해도, 도구가 미리 알아채고 거부해요.

⚠️ 처방은 실제로 써서 확인까지 끝냈어요. 그래도 처음 쓸 땐 중요한 파일은 따로 복사해 두는 걸 권장해요.

6-B단계 두 설명서 맞추기(동기화)

클로드코드용(CLAUDE.md)과 코덱스용(AGENTS.md)을 둘 다 쓰신다면, 이 단계로 두 파일이 서로 다른 안전 규칙을 갖고 있지 않은지 확인할 수 있어요. (이 기능 이름 = 동기화, 실사용 확인 완료)

  1. 입력창에 치기: 
    /sodam-context:sync
  2. 비교할 두 파일의 경로를 알려주세요(예: CLAUDE.md와 AGENTS.md).
  3. 결과로 "이 규칙은 클로드용에만 있어요(○번째 줄)" 처럼 알려줘요.
  4. 파일을 대신 고치진 않아요 — 어느 쪽에 맞출지는 사용자가 직접 정해서 손으로 옮기면 돼요. 실수로 다른 내용까지 바뀌는 위험을 막기 위한 설계예요.

💡 하나의 AI 도구만 쓰신다면(클로드코드만, 또는 코덱스만) 이 단계는 건너뛰어도 괜찮아요.

당황하지 마세요. 아래 표대로 하면 돼요.

8단계 안전 약속

이 도구가 지키는 약속이에요. 안심하세요.

  • 🔒 비밀번호·키: 내용을 안 보고 "있다"까지만 확인하고 가려서 보여줘요. 자동으로 안 지워요.
  • ✋ 확인 먼저: 사용자가 "네" 하기 전엔 파일을 만들지도 고치지도 않아요.
  • 🌐 인터넷 안 씀: 검진·문진·처방은 내 컴퓨터 안에서만 돌아가요(설치할 때만 인터넷 필요).
  • ♻️ 안전하게 고침: 처방은 백업을 먼저 뜨고, 임시파일에 쓴 뒤 바꿔치기해서 도중에 멈춰도 원본이 안 깨져요.
  • 🛡️ 적용 자체가 백업을 강제해요(2026-07-27 강화): "다듬기"를 실행하는 코드 안에 백업이 내장돼 있어서, 어떻게 불러도 백업 없이 원본이 바뀌는 일이 없어요.
  • 🔍 한 파일만 봐요: 코덱스는 상위 폴더까지 합쳐서 보지만, 클로드코드는 지금은 지정한 파일 하나만 봐요. 여러 폴더에 규칙을 나눠 두셨다면 각각 따로 점검해 주세요.
  • 🛑 저장 전에 미리 막아요(2026-07-17 실사용 확인 완료): 설명서에 진짜 비밀키가 들어가거나 너무 길어지면(300줄/32KB 이상) 저장 전에 막고, 애매하게 긴 정도(200~299줄)면 "그래도 저장할까요?"라고 물어요. 실제 사용 화면에서 252줄짜리 내용을 저장하려 할 때 이 확인창이 정말로 뜨는 것까지 직접 확인했어요.
  • 🔗 동기화는 알려만 줘요: 클로드용·코덱스용 설명서 중 한쪽에만 있는 안전 규칙을 찾아서 줄 번호로 알려드려요. 파일을 대신 합치거나 고치진 않아요 — 실수로 다른 내용까지 바뀌면 위험하니까요.
  • 🛡️ 되돌리기 소스도 확인해요(2026-07-13 추가): "되돌리기"는 이 도구가 실제로 만든 백업 폴더 안의 파일만 써요. 다른 아무 파일이나 백업인 척 지정해도 거부돼요 — 엉뚱한 내용이 실수로 설명서에 복사되는 걸 막기 위해서예요.
  • 🛡️ 백업 대상도 확인해요(2026-07-27 추가): "백업"을 뜰 때도 대상이 자격증명 폴더(.ssh·.aws 등)나 시스템 폴더처럼 민감한 위치면 미리 거부해요 — 자격증명 파일 내용이 백업 폴더에 그대로 복사되는 걸 막기 위해서예요.
  • 🗓️ 정기 점검 알림도 내용은 저장 안 해요(2026-07-15 추가): "언제 마지막으로 점검했는지" 기록은 파일 경로랑 시각(날짜·시간)만 저장해요. 설명서에 뭐라고 적혀 있는지는 이 기록에 전혀 안 들어가요.
  • 🔢 참고 점수는 숨김 계산이 아니에요(2026-07-15 추가): 점수를 만들려고 파일을 다시 읽지 않아요. 검진이 이미 찾아낸 문제 개수로 그 자리에서 계산하고, 계산 방법(확정 -15점·의심 -5점)도 전부 공개해요.
  • 🙇 "무조건 안전" 장담 안 해요: 정해진 형태만 잡으니, 중요한 비밀번호는 직접 챙기세요.

데이터 흐름(쉽게): 원본 파일은 도구가 속으로만 읽고, AI에게는 요약(비밀키 값 없음) 만 전달돼요. 그래서 비밀키가 새지 않아요.
