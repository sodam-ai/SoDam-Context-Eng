# AI 사용설명서 처방 (SoDamContext)

당신(AI)은 **개발도 AI도 처음인 사람**의 AI 사용설명서를 안전하게 다듬습니다.
검진에서 찾은 문제(군더더기·중복)를 **백업 후 사용자가 확인한 뒤에만** 수정합니다.

> 용어 숨김: 사용자에게는 'CLAUDE.md' 대신 **"AI 사용설명서"** 라고 부릅니다.

## ★ 절대 안전 규칙 (어기면 사고)

1. **원본 파일을 직접 열어 읽지 마세요.** 처방 도구(`checkup-cli.mjs`)의 JSON 결과만 사용합니다.
2. **사용자 확인 없이 파일을 절대 수정하지 마세요.** 미리보기 → 확인 → 쓰기 순서 절대 유지.
3. **비밀키가 있으면 자동 삭제하지 마세요.** "비밀키가 있어요. 직접 지워주세요"라고 안내만.
4. **백업 실패 시 처방을 즉시 중단하세요.** 백업 없이 원본 수정 절대 금지.
5. **안전·금지 키워드(절대/금지/never/must/force push 등) 포함 줄은 처방에서 제외합니다.**

> **실행 경로(클로드코드/코덱스 공통)**: 아래 명령의 `${CLAUDE_PLUGIN_ROOT}`는 **클로드코드 전용**(플러그인 설치 폴더)입니다.
> **코덱스**엔 이 변수가 없으니, 클론한 `SoDam-Context-Eng` **저장소 루트에서** 실행하고 경로를 `lib/…`로 바꿔 쓰세요
> (예: `node "lib/checkup-cli.mjs" "<파일 절대경로>" --action backup`). 파일은 항상 **절대경로**로 넘깁니다. (도구 로직은 실행 폴더와 무관하게 `rules/`를 찾습니다.)

## 처방 순서

1. **검진 먼저 확인**: 처방 전 `/sodam-context:checkup`을 먼저 실행했는지 확인합니다.
   - 검진 없이 "고쳐줘" 요청이면: "먼저 검진을 해볼게요"라고 안내 후 검진 실행.

2. **처방 대상 파일 확인**: `CLAUDE.md`(클로드코드용)·`AGENTS.md`(코덱스용) 중 어떤 파일인지 확인합니다.

3. **백업 실행** (처방 전 필수):
   ```
   node "${CLAUDE_PLUGIN_ROOT}/lib/checkup-cli.mjs" "<파일 절대경로>" --action backup
   ```
   - 백업 결과에 `backupPath`가 있으면 "백업 완료: `<경로>`" 안내.
   - 결과에 `note` 필드가 있으면(Harness로 백업된 경우) 그 문구를 그대로 이어서 안내하세요 —
     "되돌릴 때 이 도구가 아니라 Harness로 해야 한다"는 중요한 정보라 빠뜨리면 안 됩니다.
   - 백업 실패(에러)면 **즉시 중단** — "백업에 실패해서 처방을 멈췄어요. 원본은 그대로예요."

4. **처방 미리보기 생성**:
   ```
   node "${CLAUDE_PLUGIN_ROOT}/lib/checkup-cli.mjs" "<파일 절대경로>" --action preview
   ```
   - 결과의 `originalLines`(원래 줄 수)·`proposedLines`(처방 후 줄 수)·`removedCount`(줄어드는
     개수)·`shrunk`(작아졌는지)를 쉬운 한국어로 설명합니다. (★정정 2026-08-20: 예전엔 "`preview`
     필드"라고 잘못 적혀 있었으나, 실제 응답엔 `preview`라는 중첩 필드가 없고 이 4개가 최상위에
     그대로 담겨 있습니다 — `lib/checkup-cli.mjs`의 `preview` 액션 실제 코드로 확인.)
   - 예: "20줄 → 17줄로 줄어요. 중복된 규칙 3개를 뺄게요."
   - `safe: false`면: "이미 잘 정리돼 있어서 처방이 필요 없어요."

5. **사용자 확인 요청** (반드시):
   ```
   "이렇게 바꿔도 괜찮을까요? (예/아니오)"
   ```
   - "아니오" 또는 취소 → 처방 없이 종료. "원본은 그대로예요."
   - "예" → 다음 단계

6. **처방 적용 (쓰기)**:
   ```
   node "${CLAUDE_PLUGIN_ROOT}/lib/checkup-cli.mjs" "<파일 절대경로>" --action apply
   ```
   - 성공 시, 결과에 `note` 필드가 **없으면**: "처방 완료했어요. 백업은 `<경로>`에 있어요. 문제
     생기면 되돌릴 수 있어요."
     `note` 필드가 **있으면**(Harness로 백업된 경우): "처방 완료했어요. 백업은 `<경로>`에 있어요.
     단, 이 백업은 Harness로 만들어져서 문제 생기면 이 도구가 아니라 **Harness 자체 명령으로**
     되돌려야 해요."
   - 실패 시: "처방 중 오류가 났어요. 원본은 그대로예요. 백업: `<경로>`"

7. **처방 후 재검진** (선택, 권장):
   - "처방이 잘 됐는지 한 번 더 검진해 드릴까요?"

## 되돌리기 안내

사용자가 "되돌려줘" / "이전으로" 요청 시 (첫 인자=되돌릴 원본 파일, `--target`=백업 파일):
```
node "${CLAUDE_PLUGIN_ROOT}/lib/checkup-cli.mjs" "<원본 파일 경로>" --action restore --target "<백업 경로>"
```
"`<원본 파일 경로>`를 처방 전 상태(`<백업 경로>`)로 되돌릴게요. 확인할까요?"

## 비밀키 발견 시

처방 중 검진 결과에 비밀키(`secret.findings`)가 있으면:
- 자동 삭제 **절대 금지**
- "AI 설명서에 비밀키로 보이는 게 있어요: `sk-ant-…REDACTED`
  → 직접 편집기로 열어서 지워주세요. 저는 내용을 안 보고 '있다'까지만 확인했어요."

## 처방 범위 (Phase 1)

처방이 하는 것:
- 완전히 같은 줄이 여러 번 → 첫 번째만 남기고 나머지 제거
- 연속 빈 줄 3개 이상 → 최대 1개로 압축

처방이 하지 않는 것 (Phase 1 범위 외):
- 비밀키 자동 삭제
- 내용이 비슷한 규칙 자동 병합 (Phase 3)
- 구조 재편성 (Phase 3)

## 다음 단계 안내

- 처방 후: "처방이 끝났어요. 이제 AI에게 다시 말을 걸어보시면 더 또렷하게 대답할 거예요."
- 코덱스(`AGENTS.md`) 처방 후: 상위 폴더 설명서도 확인 권장.
