# AI 사용설명서 동기화 점검 (SoDamContext)

당신(AI)은 **개발도 AI도 처음인 사람**의 `CLAUDE.md`(클로드코드용)와 `AGENTS.md`(코덱스용) 사이에
**안전·금지 규칙이 한쪽에만 있어서 반대쪽 AI가 그 규칙을 모르는 상황**이 없는지 점검합니다.

> 용어 숨김: 사용자에게는 각각 **"클로드용 설명서"**·**"코덱스용 설명서"** 라고 부릅니다.

## ★ 절대 안전 규칙 (어기면 사고)

1. **원본 파일을 직접 열어 읽지 마세요.** 점검 도구(`checkup-cli.mjs --action sync-check`)의 JSON 결과만 사용합니다. 이 도구는 파일 내용을 절대 출력하지 않습니다(줄 번호만).
2. **두 파일을 절대 합치거나 고치지 마세요.** 이 기능은 **리포트 전용**입니다 — 쓰기 동작이 아예 없습니다.
3. **`@AGENTS.md` 가져오기(import)를 권하지 마세요.** 겉보기엔 "정리"처럼 보여도, import한 내용은 실행 시 전부 그대로 불러와져서 **설명서가 가벼워지지 않습니다.** "가벼워진다"고 말하면 안 됩니다(과장 금지 원칙).
4. **의미(뜻)가 통하는지는 판단하지 마세요.** 이 도구는 완전히 같은 뜻의 문장인지까지는 못 봅니다(예: "npm 쓰세요" vs "pnpm 쓰세요" 같은 충돌은 다음 버전 몫). 지금은 "안전 규칙 문구가 한쪽에만 있다"만 알려줍니다.

> **실행 경로(클로드코드/코덱스 공통)**: 아래 명령의 `${CLAUDE_PLUGIN_ROOT}`는 **클로드코드 전용**(플러그인 설치 폴더)입니다.
> **코덱스**엔 이 변수가 없으니, 클론한 `SoDam-Context-Eng` **저장소 루트에서** 실행하고 경로를`lib/…`로 바꿔 쓰세요.
> 파일은 항상 **절대경로**로 넘깁니다.

## 점검 순서

1. **두 파일 다 있는지 확인**: `CLAUDE.md`·`AGENTS.md` 둘 다 있어야 점검이 됩니다.
   - 하나만 있으면: "아직 한쪽 설명서만 있어서 동기화 점검은 필요 없어요. 먼저 검진이나 문진을 해볼까요?"

2. **점검 실행** (첫 인자=CLAUDE.md 절대경로, `--target`=AGENTS.md 절대경로):
   ```
   node "${CLAUDE_PLUGIN_ROOT}/lib/checkup-cli.mjs" "<CLAUDE.md 절대경로>" --action sync-check --target "<AGENTS.md 절대경로>"
   ```

3. **결과를 쉬운 한국어로 안내**:
   - `applicable: false`면: "두 설명서가 다 있어야 점검할 수 있어요."
   - `onlyInClaude`가 비어있지 않으면: "클로드용 설명서 N번째 줄에 있는 안전 규칙이 코덱스용 설명서엔 없어요. 코덱스가 이 규칙을 모를 수 있어요."
   - `onlyInAgents`가 비어있지 않으면: "코덱스용 설명서 N번째 줄에 있는 안전 규칙이 클로드용 설명서엔 없어요."
   - 둘 다 비어있으면: "두 설명서의 안전 규칙이 서로 잘 맞아요. 손댈 필요 없어요."
   - **줄 번호만 안내하고, 그 줄이 뭐라고 적혀있는지는 말하지 않습니다**(도구가 내용을 안 돌려주기 때문 — 사용자가 직접 그 줄을 열어보게 안내).

4. **직접 옮기도록 안내만** (자동 반영 절대 금지):
   ```
   "N번째 줄을 직접 열어보시고, 필요하면 다른 설명서에도 같은 규칙을 손으로 추가해 주세요.
   제가 대신 옮기진 않아요 — 실수로 다른 내용까지 바뀌면 위험하니까요."
   ```

## 점검 범위 (v1)

이 점검이 하는 것:
- 안전·금지 키워드(절대/금지/never/must/secret 등)가 포함된 줄만, 다른 파일에 비슷한 줄이 있는지 문자열 비교

이 점검이 하지 않는 것 (다음 버전 몫):
- 파일을 합치거나 자동으로 고치기 (절대 안 함 — 자동적용 금지 원칙)
- 안전 키워드 없는 일반 설명 문장의 모순 판단 (뜻 기반 비교는 Phase 3)
- 코덱스의 여러 상위 폴더 설명서(병합 체인)까지 함께 비교 (지금은 두 파일 1:1만)
