# SoDamContext — AI 사용설명서 건강검진 🩺

> **코드를 몰라도** AI(클로드코드·코덱스)가 내 프로젝트를 잘 이해하도록,
> **"AI 사용설명서"(CLAUDE.md·AGENTS.md)를 쉬운 한국어로 점검하고 만들어 주는** 도구입니다.

---

## 0. 이게 뭔가요? (1분 설명)

- AI 코딩 도구(클로드코드·코덱스)는 **`CLAUDE.md` / `AGENTS.md`** 라는 **"AI 사용설명서"** 파일을 읽고 일해요.
- 이 설명서가 **너무 길거나, 비밀번호가 들어 있거나, 서로 모순되면** AI가 헷갈리고 비용도 늘어납니다.
- **SoDamContext**는 이 설명서를 **쉬운 한국어로 건강검진**하고, 없으면 **쉬운 질문 몇 개로 만들어** 줍니다.
- 어려운 말은 숨기고(`CLAUDE.md` → **"AI 사용설명서"**), "왜요?"라고 물으면 진짜 이유를 알려줘요.

> ⚠️ **정직한 안내:** 지금 버전에서 **작동하는 기능은 "검진(점검)"·"문진(만들기)"·"처방(다듬기)" 세 가지**입니다.
> 검진·문진은 실사용까지 검증됐고, **처방은 백업+확인 후 안전하게 다듬기**(코드·자동검증 완료 — 실사용 관찰은 아직 적어 '신규'로 표기).
> **"예방(자동 차단)"·"두 파일 자동 동기화"는 아직 준비 중(예정)**입니다.

## 1. 사전 준비물 (필요한 프로그램)

| 준비물 | 필요한 이유 | 확인 / 설치 방법 |
|---|---|---|
| **클로드코드(Claude Code)** | 이 도구가 작동하는 곳 | 이미 쓰고 계시면 OK |
| **Node.js 18 이상** | 검진 도구가 속으로 Node를 사용 | 입력창에 `!node --version` → `v18` 이상 숫자가 나오면 OK. 없으면 [nodejs.org](https://nodejs.org) 에서 **LTS** 버튼으로 설치 |
| (선택) **코덱스(Codex)** | 코덱스의 `AGENTS.md`도 다루려면 | 코덱스 쓰는 분만 |

- 운영체제: **Windows · macOS** 둘 다 됩니다. (이 안내의 경로 예시는 Windows 기준)
- 인터넷: 설치할 때만 필요. 검진·문진은 **100% 내 컴퓨터 안에서** 돌아갑니다(데이터를 밖으로 안 보냄).

## 2. 다운로드 · 설치 방법

### 클로드코드 (자동 설치)
클로드코드 **입력창**(채팅 치는 칸)에 아래를 **한 줄씩** 붙여넣고 Enter 하세요.

```
/plugin marketplace add sodam-ai/SoDam-Context-Eng
/plugin install sodam-context
```
- 또는 `/plugin` 만 쳐서 **메뉴**에서 SoDamContext를 찾아 **Install** 을 눌러도 됩니다.
- **설치 후에는 클로드코드를 한 번 껐다 켜세요(재시작).** 그래야 명령어가 목록에 떠요.

> 💡 **내 컴퓨터의 폴더에서 바로 쓰는 경우**(개발·테스트): 위 `sodam-ai/SoDam-Context-Eng` 자리에 **그 폴더의 절대경로**를 넣으면 됩니다.
> 예: `/plugin marketplace add D:\...\SoDam-Context-Eng`

### 코덱스 (수동 설치)
코덱스에는 마켓플레이스가 없어, **저장소를 통째로 clone해 그 루트 폴더에서** 씁니다(스킬만 복사하면 `lib`·`rules`가 빠져 오류). 단계별 안내는 **`GUIDE.md` 2-B단계** 또는 저장소의 **`codex/README.ko.md`** 참고. (스킬은 저장소 루트에서 실행 — 각 SKILL에 안내됨)

## 3. 빠른 시작 (5분)

설치·재시작이 끝났다면:

1. **점검만 하고 싶을 때** — 입력창에:
   ```
   /sodam-context-checkup
   ```
   "어느 파일을 볼까요?"라고 물으면, 점검할 폴더의 `CLAUDE.md` 경로를 알려주면 돼요.

2. **설명서가 아직 없을 때(처음 만들 때)** — 입력창에:
   ```
   /sodam-context-intake
   ```
   쉬운 질문 5~6개에 답하면, **미리보기 → "만들까요?" 확인 후** 작은 설명서를 만들어 줍니다.

> 자연어로 **"sodam-context로 내 AI 설명서 점검해줘"** 처럼 말해도 됩니다.

## 5. 사용 · 작동 방법

- **검진**: 도구가 **원본 파일을 직접 열지 않고**, 속 검사기를 돌려 **결과만** 봅니다. 그래서 **비밀키가 새지 않아요**. 리포트는 **점수 대신 "문제 ○건"** 으로, 비밀키는 **가린 채(`sk-ant-…REDACTED`)** 보여줍니다. "왜요?"라고 답하면 이유·근거를 설명합니다.
- **문진**: 질문 → **미리보기 → "만들까요?" 확인 → 그때만 파일 생성**. 묻지 않고 마음대로 만들지 않습니다. 만든 설명서는 **200줄 이하·비밀키 0**.
- **코덱스(`AGENTS.md`)**: 코덱스는 상위 폴더·전역 설명서까지 **합쳐서** 읽어요. 검진이 그 **합산 용량(32KiB 한도)** 까지 확인합니다. (한글은 글자당 3바이트라 글자 수보다 용량이 큽니다.)

## 8. 문제 · 오류 대처 (Troubleshooting)

| 증상 | 원인 | 해결 |
|---|---|---|
| 명령어가 목록에 안 보임 | 설치 후 **재시작 안 함** | 클로드코드 **완전히 껐다 켜기** |
| 재시작해도 안 보임 | 설치본 갱신 안 됨 | `! claude plugin marketplace update sodamcontext-marketplace` 후 다시 재시작 |
| "node를 찾을 수 없음" | Node.js 없음/낮은 버전 | [nodejs.org](https://nodejs.org) LTS 설치 후 재시작 |
| 엉뚱한(다른) 기능이 답함 | 이름이 비슷한 다른 플러그인이 가로챔 | 자연어 대신 **`/sodam-context-...`** 슬래시 명령 사용 |
| 검진이 엉뚱한 파일을 봄 | "어느 폴더?"가 모호 | 점검할 파일의 **절대경로**를 정확히 알려주기 |
| 비밀번호가 있다고 나옴 | 설명서에 키로 보이는 게 있음 | 그 키를 **재발급**하고 설명서에서 빼기(환경변수로) — 도구는 자동으로 안 지웁니다 |

## 9. 제거 (Uninstall)

```

```
