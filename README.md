# SoDamContext — AI 사용설명서 건강검진 🩺

> **코드를 몰라도** AI(클로드코드·코덱스)가 내 프로젝트를 잘 이해하도록,
> **"AI 사용설명서"(`CLAUDE.md`·`AGENTS.md`)를 쉬운 한국어로 점검·생성·정리**해 주는 도구입니다.
>
> 컴퓨터·AI가 처음이어도 괜찮아요. 이 문서는 **하나씩 따라 하면 되는** 순서로 쓰여 있습니다.

> ⚠️ **정직한 현재 상태 (2026-07-11 기준)**
> - **작동(실사용 라이브 검증 완료):** 검진(점검) · 문진(만들기) · 처방(다듬기) · 코덱스 검진 — **클로드코드·코덱스 양쪽 실제 세션에서 확인됨**
> - **보안 강화:** 민감한 위치(시스템·자격증명 폴더) 쓰기 자동 거부 기능 추가
> - **준비 중(예정):** 예방(자동 사전 차단) · 두 파일 자동 동기화 — 착수 가능 상태이나 아직 시작 전
> - 과장하지 않습니다. "100% 안전·완벽"이라고 **말하지 않습니다.**

## 1. 이게 뭔가요

- AI 코딩 도구(**클로드코드**·**코덱스**)는 일을 시작하기 전에 **`CLAUDE.md` / `AGENTS.md`** 라는 파일을 읽습니다. 이 파일이 바로 **"AI 사용설명서"** 예요. (AI에게 "이 프로젝트는 이렇게 다뤄줘"라고 미리 적어 두는 쪽지입니다.)
- 이 설명서가 **너무 길거나, 비밀번호(키)가 들어 있거나, 서로 모순되면** AI가 헷갈리고, 대답이 부정확해지고, 비용도 늘어납니다.
- **SoDamContext**는 그 설명서를 **쉬운 한국어로 건강검진**하고, 없으면 **쉬운 질문 몇 개로 작게 만들어** 주고, 문제가 있으면 **안전하게 다듬어** 줍니다.
- 어려운 말은 숨깁니다(`CLAUDE.md` → **"AI 사용설명서"**). "왜요?"라고 물으면 그때 진짜 이유를 알려줘요.

> 💡 **한 줄 요약:** "AI가 내 프로젝트를 잘 알아듣게 해 주는 설명서를, 코드 몰라도 점검·정리할 수 있게 도와주는 도구."

> 📱 **참고(정직):** 이 도구는 **컴퓨터(Windows·macOS)** 의 클로드코드·코덱스 **안에서** 작동합니다. **휴대폰 앱이 아닙니다.** 스마트폰만 있는 경우엔 사용할 수 없어요.

## 3. 다운로드와 설치 방법

### 3-1. 클로드코드 (자동 설치, 권장)

클로드코드 **입력창**에 아래 두 줄을 **한 줄씩** 붙여넣고 각각 Enter 하세요.

```
/plugin marketplace add sodam-ai/SoDam-Context-Eng
```
```
/plugin install sodam-context
```

- 또는 `/plugin` 만 쳐서 **메뉴**에서 SoDamContext를 찾아 **Install** 을 눌러도 됩니다.
- **설치 후에는 클로드코드를 완전히 껐다 켜세요(재시작).** 그래야 명령어가 목록에 떠요.

> 💡 **내 컴퓨터 폴더에서 바로 쓰는 경우**(개발·테스트): 위 첫 줄의 `sodam-ai/SoDam-Context-Eng` 자리에 **그 폴더의 절대경로**를 넣으세요.
> 예: `/plugin marketplace add D:\...\SoDam-Context-Eng`

### 3-2. 코덱스 (수동 설치)

코덱스에는 플러그인 마켓이 없어서, **저장소를 통째로 받아 그 안에서** 씁니다. (스킬 폴더만 복사하면 검진 도구가 쓰는 `lib`·`rules` 폴더가 빠져서 "파일을 찾을 수 없어요" 오류가 나요.)

1. 터미널(명령 프롬프트)에 한 줄씩:
   ```
   git clone https://github.com/sodam-ai/SoDam-Context-Eng.git
   cd SoDam-Context-Eng
   ```
2. **코덱스를 이 저장소 루트 폴더에서 시작**하세요. (루트에 `AGENTS.md`·`skills`·`lib`·`rules`가 다 있어요.)
3. 자세한 단계·FAQ는 저장소의 **`codex/README.ko.md`** 또는 이 문서 아래 **[사용 방법](#6-사용-방법)** 참고.

> 왕초보용 그림 같은 단계별 안내는 같은 폴더의 **`GUIDE.md`**(한국어)·**`GUIDE.en.md`**(영어)에 있어요.

## 4. 빠른 시작

설치·재시작이 끝났다면, 딱 두 가지만 기억하세요.

1. **이미 설명서가 있을 때 → 점검(검진):**
   ```
   /sodam-context-checkup
   ```
   "어느 파일을 볼까요?"라고 물으면, 점검할 폴더의 `CLAUDE.md` 경로(절대경로)를 알려주세요.

2. **아직 설명서가 없을 때 → 만들기(문진):**
   ```
   /sodam-context-intake
   ```
   쉬운 질문 5~6개에 답하면, **미리보기 → "만들까요?" 확인 후** 작은 설명서를 만들어 줍니다.

> 자연어로 **"sodam-context로 내 AI 설명서 점검해줘"** 처럼 말해도 됩니다.

## 5. 실행 방법

이 도구는 **직접 켜는 프로그램이 아니라**, 클로드코드·코덱스 안에서 **명령/자연어로 부르면** 작동합니다.

- **클로드코드:** 입력창에 슬래시 명령을 칩니다. 예: `/sodam-context-checkup`, `/sodam-context-intake`, `/sodam-context-treat`.
- **코덱스:** 슬래시 명령이 없으니 **자연어**로 부릅니다. 예: "내 AGENTS.md 건강검진 해줘", "설명서 고쳐줘". (반드시 **저장소 루트 폴더**에서 코덱스를 실행하세요.)
- 검사할 파일은 **절대경로**로 알려주면 가장 정확합니다. 예: `C:\내프로젝트\CLAUDE.md`.

## 6. 사용 방법

### 6-1. 검진(점검) — `✅ 작동`

1. `/sodam-context-checkup` 입력.
2. "어느 파일?" 물으면 절대경로 알려주기.
3. 잠시 후 **쉬운 리포트**가 나옵니다:
   - "문제 ○건" 처럼 **개수**로 보여줘요(점수는 일부러 숨김 — 과장 방지).
   - 비밀번호/키가 있으면 **가린 채**(`sk-ant-…REDACTED`)로만.
   - **낡음·자동생성 미정제·스킬누수** 같은 항목은 "의심"으로(오탐 가능성 함께 안내).
   - 더 궁금하면 **`왜요?`** 라고 답하면 이유·근거를 설명해요.

### 6-2. 문진(만들기) — `✅ 작동`

1. `/sodam-context-intake` 입력.
2. "어느 폴더?" 물으면 경로를 주거나 **"지금 이 폴더"** 라고 답하기.
3. 쉬운 질문에 하나씩 답하기(무슨 프로젝트/언어·도구/꼭 지킬 규칙/하지 말 것/말투).
4. AI가 **만들 내용을 먼저 보여주고** "이대로 만들까요?"라고 물어요 → **`네`** 라고 해야 그때 파일이 생겨요.
5. 만든 설명서는 **200줄 이하·비밀키 0**. 이어서 "검진도 해볼까요?"에 `네` 하면 점검까지.

### 6-3. 처방(다듬기) — `✅ 작동(라이브 검증 완료)`

1. 검진에서 문제가 나오면 `/sodam-context-treat` 입력.
2. **백업을 먼저** 뜨고, **무엇을 바꿀지 미리보기**를 보여줘요.
3. **`네`** 라고 해야만 실제로 고칩니다(중복 줄·불필요한 빈 줄 정리).
4. **되돌리기(restore)** 지원 — 마음에 안 들면 백업으로 복구.
5. **안전·금지 규칙 줄**(예: "절대", "never", "비밀번호 금지")은 **자동으로 보존**합니다(지우지 않아요).

> ⚠️ 처방은 실제 세션 라이브 검증까지 완료됐습니다(안전키워드 100% 보존·되돌리기 정확성 확인). 그래도 처음 쓸 땐 중요한 파일은 따로 복사해 두는 걸 권장합니다.

## 7. 작동 방법

- **검진:** 도구가 **원본 파일을 직접 열지 않습니다.** 속 검사기(`checkup-cli.mjs`)를 돌려 **결과(요약 JSON)만** 봐요. 그래서 **비밀키가 새지 않습니다.** 리포트는 **점수 대신 "문제 ○건"**, 비밀키는 **가린 채**로만 보여줍니다.
- **문진:** 질문 → **미리보기 → "만들까요?" 확인 → 그때만 파일 생성.** 묻지 않고 마음대로 만들지 않습니다.
- **처방:** **백업 먼저 → 미리보기 → 확인 → 안전하게 쓰기**(임시파일에 쓴 뒤 이름 바꾸기 방식이라, 도중에 멈춰도 원본이 안 깨져요). 처방 뒤엔 파일이 **더 작아져야** 성공으로 봅니다.
- **코덱스(`AGENTS.md`):** 코덱스는 상위 폴더·전역 설명서까지 **합쳐서** 읽어요. 검진이 그 **합산 용량(32KiB 한도)** 까지 확인합니다. (한글은 글자당 3바이트라 글자 수보다 용량이 큽니다.)

- **테스트 대폭 강화:** 자동 테스트 67개 → **82개**로 확대(경계값·실패 상황·보안 경로 포함), 전부 통과.

## 12. 아키텍처

기술에 관심 있는 분을 위한 내부 구조입니다. (몰라도 사용에는 지장 없어요.)

- **데이터 주도(Data-driven):** 검진·처방의 판정 규칙은 코드가 아니라 `rules/*.json` 에 있습니다. 새 검진을 추가하려면 **JSON 배열에 객체 하나** 넣으면 돼요(코드 변경 0).
- **CLI–JSON 경계(안전의 핵심):** AI·스킬은 원본 파일을 **직접 읽지 않고**, `lib/checkup-cli.mjs` 가 내보내는 **요약 JSON만** 봅니다. 비밀키 '값'은 어떤 결과·로그에도 들어가지 않아요.
- **엔진(lib) 구성:** `scan-secrets`(비밀키 탐지) · `checkup-rules`(크기·린트중복·의심 탐지) · `intake-verify`(생성물 안전 게이트) · `treat`+`treat-verify`(정리·안전키워드 보존·회귀검증) · `backup`(원자적 백업·복구) · `codex-merge`(코덱스 병합체인·32KiB) · `path-safety`(민감 경로 쓰기 차단) · `checkup-cli`(오케스트레이터: 검진/백업/미리보기/적용/복구).
- **의존성 0:** 외부 npm 패키지를 쓰지 않습니다(공급망 위험 최소화). **Node 18+ ESM**, **100% 로컬**(네트워크 전송 0).
- **진입점(스킬) 3종:** `sodam-context-intake`·`sodam-context-checkup`·`sodam-context-treat` — 클로드코드·코덱스 공통.

## 13. 보안과 데이터 흐름

- **비밀키 미열람(T1):** 도구는 비밀키 '값'을 **읽거나 출력하지 않습니다.** "있다"까지만 확인하고 **가려서**(`sk-ant-…REDACTED`) 보여줍니다. **자동으로 지우지 않아요**(오탐 위험 때문).
- **자동 변경 없음(Fail-Closed):** 사용자가 **"네"** 라고 하기 전에는 파일을 **만들지도 고치지도** 않습니다.
- **네트워크 0:** 검진·문진·처방은 **내 컴퓨터 안에서만** 돌아갑니다. 인터넷은 설치할 때만 필요.
- **원자적 쓰기 + 백업 우선:** 처방은 임시파일에 쓴 뒤 이름을 바꿔 반영하고, **백업이 실패하면 즉시 중단**합니다.
- **안전키워드 보존:** "절대/금지/never/must/항상/secret/force push" 같은 중요 규칙이 든 줄은 **자동 보존**(정리에서 제외).
- **민감한 위치엔 아예 쓰지 않음:** 처방·되돌리기 대상이 홈 폴더 자체·자격증명 폴더(`.ssh`·`.aws` 등)·시스템 폴더로 잘못 지정되면, 실행 전에 **자동으로 거부**하고 이유를 알려줍니다.
- **검진은 지정한 파일 하나만 봅니다:** 코덱스(`AGENTS.md`)는 상위 폴더·전역 설명서까지 합쳐서 확인하지만, 클로드코드(`CLAUDE.md`)는 지금은 **지정한 파일 하나만** 봅니다. 하위 폴더의 별도 `CLAUDE.md`나 `.claude/rules/`에 규칙을 나눠 두셨다면, 그 파일들은 자동으로 훑지 않으니 각각 따로 검진해 주세요.
- **정직한 한계:** 정해진 패턴만 잡으므로 **"100% 안전·완벽 탐지"는 보장하지 않습니다**(참고용). 중요한 키는 직접 재발급/관리하세요.

**데이터 흐름(검진):**
```
[원본 설명서 파일]
      │  (도구가 내부에서만 읽음 — AI는 원본을 직접 안 봄)
      ▼
[checkup-cli.mjs = 내부 검사기]
      │  요약 JSON만 생성 (비밀키 '값' 없음 · 마스킹 표시만)
      ▼
[AI / 스킬] → 쉬운 한국어 리포트("문제 ○건", 가린 키)
```

## 15. 자주 묻는 질문

**Q. "AI 사용설명서"가 정확히 뭔가요?**
A. AI 코딩 도구가 일 시작 전에 읽는 `CLAUDE.md`(클로드코드용)·`AGENTS.md`(코덱스용) 파일이에요. "이 프로젝트는 이렇게 다뤄줘"라고 적어 두는 쪽지입니다.

**Q. 내 파일 내용이 밖으로 나가나요?**
A. 아니요. 검진·문진·처방은 **100% 내 컴퓨터 안**에서 돌아갑니다. 인터넷은 설치할 때만 필요해요.

**Q. 비밀번호를 자동으로 지워주나요?**
A. **아니요.** "있다"까지만 확인하고 **가려서** 보여줄 뿐, 자동으로 지우지 않습니다(오탐 위험). 직접 확인하고 재발급하세요.

**Q. 점수는 왜 안 보여줘요?**
A. 검증되지 않은 점수는 과장이 될 수 있어 **일부러 숨겼어요.** 대신 "문제 ○건"으로 봅니다.

**Q. 한글이 깨져요.**
A. Node.js가 v18 이상인지 확인하세요. Windows에서는 터미널 인코딩이 UTF-8인지도 확인해요.

**Q. 자동 허용(권한) 모드에서 써도 되나요?**
A. 자동 허용 모드는 확인 단계를 건너뛸 수 있어요. 안전을 위해 **기본(ask) 모드**를 권장합니다.

**Q. 클로드코드와 코덱스를 같이 써도 되나요?**
A. 네. 같은 프로젝트에서 클로드코드는 `CLAUDE.md`, 코덱스는 `AGENTS.md`를 각각 읽어요. 두 파일이 공존해도 문제없습니다.

**Q. 업데이트는 어떻게 하나요?**
A. 클로드코드는 `! claude plugin marketplace update sodamcontext-marketplace` 후 재시작. 코덱스(로컬 저장소)는 폴더에서 `git pull`.

**Q. 비용이 드나요?**
A. 이 도구 자체는 로컬에서 돌아 별도 요금이 없지만, **AI(클로드·코덱스) 사용에는 각 제공사의 요금이 적용**됩니다(우리 범위 밖).
